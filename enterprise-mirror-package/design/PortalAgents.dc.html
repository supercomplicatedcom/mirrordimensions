Three ways an agent can enter

Hosted container
The agent's own image runs inside the sandbox. Strongest containment and the fullest record.
Managed browser
The mirror provides the browser; the agent drives it. For agents that work through web pages.
Remote gateway
The agent stays on its vendor's platform and reaches the mirror through a tunnel. Leaks are detected, not blocked.

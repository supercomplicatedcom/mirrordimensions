# The project's name

"MirrorDimensions" is the name of this open-source project. No one holds a registered trademark in it, and the project does not claim one. The Apache-2.0 licence covers the code; it grants no rights to any name or logo (section 6 of the licence).

So that people can tell the project apart from the work built on it, we ask that you follow these guidelines.

## Please do

- Say that your product or service works with, integrates with, or is based on MirrorDimensions.
- Use the name to refer to this project accurately, for example in articles, talks and documentation.
- Run unmodified or modified copies of the code for yourself or your organization.

## Please don't

- Use "MirrorDimensions", or a confusingly similar name, as the name of your product, service, fork or company.
- Suggest that your fork, distribution or hosted service is the official project, or endorsed by it.

If you are unsure, open an issue and ask.

## Google's Mirror Dimension for Agents

The idea of a sealed "mirror dimension" for testing agents comes from Google's [Mirror Dimension for Agents](https://blog.google/security/mirror-dimension-for-agents/), built for browser agents. This project is independent and is not affiliated with Google.
